# 知识沉淀

本目录维护"事实与日常维护入口"，与决策与设计（做什么、怎么做）和需求计划（接下来做什么）区分。

- `wiki/` 项目知识库：当前可验证状态、维护方法、常用命令、清理原则。
- `api/` API 文档：预留对外 API 文档落点；目前 API 契约以 [01-decisions/lld/01-data-and-api-design.md](../01-decisions/lld/01-data-and-api-design.md) 为唯一事实来源，未来若拆分纯 API 规范文档，落到此目录。

## 当前内容

- [Wiki · 设计进度](./wiki/01-design-progress.md)：当前可验证状态、本轮完成、近期任务。
- [Wiki · 维护指南](./wiki/02-maintenance-guide.md)：目录职责、不变量、常用验证命令、清理原则、未来扩展入口。

## 写作约束

- Wiki 只陈述"当前是什么"，不带目标或未来计划；目标体验在 PRD，未来工作在路线图。
- 维护指南的命令必须可在仓库根目录直接复制执行；命令区分宿主机、容器、托管方控制台。
- API 规范目录新增文档时，反向链接到 LLD 的对应数据模型 / 接口设计章节。
